# Code of Conduct

This project uses a simple contributor standard: be respectful, technical, and constructive.

## Expected Behavior

- Discuss ideas and code without personal attacks.
- Assume good intent while still being rigorous about correctness.
- Keep issues and pull requests focused on the project.
- Be clear when reporting security-sensitive behavior.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private security details before maintainers have had a chance to triage.
- Spam, trolling, or repeated off-topic comments.

## Enforcement

Maintainers may edit, hide, or remove comments and may block participants who repeatedly violate this standard.
